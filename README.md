# Student Mark Registration System

A Django-based web application developed to manage student marks and store student information using CSV data.

## Features

- Add student marks
- View student records
- Update student marks
- Store student data in CSV format
- Calculate and display total marks
- Visualize student marks

## Technologies Used

- Python
- Django
- HTML
- CSS
- CSV
- SQLite

## Project Structure

- `mark_registration_system/` - Main Django project
- `marks/` - Main application
- `templates/` - HTML templates
- `static/` - CSS files
- `data/` - CSV student data
- `db.sqlite3` - SQLite database
- `manage.py` - Django management file

## How to Run the Project

1. Open the project in VS Code.

2. Activate the virtual environment.

3. Install Django if needed:

```bash
pip install django
```
4. Run the Django development server:
```bash
python manage.py runserver
```
5. Open this in your browser:
```text
http://127.0.0.1:8000/
```
